# CV Template

Plantilla de portafolio y CV personal lista para clonar y personalizar, desarrollada con HTML, CSS y JavaScript puro.

Basada en el diseño original de [misteralva.github.io](https://misteralva.github.io).

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Cómo usarla

1. Clona el repositorio
```bash
   git clone https://github.com/misteralva/cv-template.git
```
2. Edita `index.html` con tu información personal
3. Ajusta los estilos en `styles.css` si lo necesitas
4. Despliégala gratis con GitHub Pages
